## 1. Где что настраивается

| Где | Что именно настраивается здесь |
|---|---|
| Инструмент («Card Roulette» в разделе Инструменты) | Общее для одного ивента: Название баланса, Скидка (числовое значение), Цена открытия (два параметра: 1.Выпадающий список с 2015 и 73032; 2.Поле для ввода - может быть несколько чисел через запятую), Уровень открытия (числовое значение). Баланс (3 сундука на одной странице, можно добавлять и удалять. Всегда нумеруются по порядку 1,2,3...) 8 предметов в каждом сундуке - пронумерованы 1-8. Item (настраиваем 3 полями: 1. выпадающий список из Weapon, Currency, FreeUpgrade, Royale, ProfileBackgroundUI, Mask, Armor, Boots, Pet, Applicable, PixelPassExp, FeatureExp; 2. поле для ввода предмета; 3. поле для ввода количества - при парсинге формируется в одну строку 1:2:3), AltItem - аналогично Item, DropChance - по умолчанию 1, изменяемый, 3 чекбокса для Pr, C, SiP и Expression - поле для ввода цифры (формат для парсинга всегда номер атрибута:GreaterEqual:введенная цифры. Номер атрибута всегда соответствует номеру сундука 1 - 91201, 2 - 92201, 3 - 93201) сохранение/загрузка/переименование баланса |
| График ивентов (окно события типа Card Roulette) | Название ивента → авто-Id из Schedule, style, segment, start/end datetime, выбор сохранённого баланса |

## 5. Реализация — подтверждено реальным прогоном на тестовой таблице

- Дублируются листы **`Settings_Template`** и **`Chests_Template`** — именно с этими именами, регистр важен.
- В `Settings_<Имя>` строка настроек пишется сразу под заголовком (первая строка данных).
- В `Chests_<Имя>` **колонка `AttributeIds` отсутствует** — она есть только в Settings как список. В Chests номер атрибута зашит только внутри Expression.
- **`ChestId` в листе Chests пишется только в первой строке каждого сундука** (остальные 7 строк — пустая ячейка, как в оригинальном шаблоне). При чтении листа код «протягивает» последний непустой ChestId вниз по пустым ячейкам, чтобы правильно сгруппировать строки в блок сундука.
- Запись идёт блоками по ChestId, как у Lottery: лишние/недостающие строки внутри блока удаляются/вставляются. Если блока для ChestId вообще нет — ошибка, авто-создание не поддерживается.
- Авто-Id берётся из максимума колонки **B** листа Schedule; если лист пуст — стартует с 1.
- Item/AltItem собираются как `{тип}:{значение}:{количество}`, Expression — автоматически по номеру сундука (90000+N×1000+201), OpenPrices — как `{валюта}:{значение}` через запятую.
