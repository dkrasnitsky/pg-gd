# Trader Van

**Статус:** готово, проверено.
**Расположение:** отдельный инструмент в разделе Инструменты (не связан с Графиком ивентов — конфиг создаётся только через инструмент).

## Таблица

**Spreadsheet:** 1qKogyjkoHpO6imV1aU5ZyWKpFuF9Hr_qPYyc8RpamfE, лист gid 1806543965.
Одна общая таблица без разделения на листы по фургонам — каждый новый фургон это просто новый блок строк, дописанный в конец.

**Колонки:** `i_season | s_style | season | Show Van In Lobby | buylimit | id | start | end | price | sale | order | content | show_timer | price_amount` (+ несколько справочных колонок правее — не трогаем).

## Логика

- `i_season` — считается как **максимум по всей колонке + 1** (в реальных данных номера идут не строго по порядку — где-то повторяются, где-то скачут — поэтому "последняя строка +1" ненадёжно). Записывается только в первую строку нового блока, у остальных строк блока — пусто.
- `s_style`, `season` — по умолчанию `basic`, поля ввода.
- `buylimit` — **своё у каждого предмета** (не общее на весь фургон).
- `id` / `order` — считаются автоматически 1..N по порядку добавления, одинаковые значения в обеих колонках.
- `start` / `end` — в инструменте только выбор даты (без времени), при записи всегда добавляется `T09:00:00`, итоговый формат совпадает с уже существующими строками (`2026-09-02T09:00:00`).
- `price` — выпадающий список: `G` (Гемы), `C` (Коины), `R` (Real), `P` (PixelPassCurrency), `E` (EventCurrency), `U` (Coupon), `F` (Craft), `B` (BattlePass).
- `sale`, `price_amount`, `buylimit` — пишутся как **настоящие числа**, не строки (иначе Google Sheets показывает значение с ведущим апострофом, как было при первой версии — баг найден и исправлен).
- `content` — свободное текстовое поле.
- `show_timer` — чекбокс (boolean).

## UI

Баланс (s_style/season/список предметов) можно сохранять/загружать локально, как у остальных фич. Кнопка «Создать конфиг» дописывает блок строк в конец таблицы.
