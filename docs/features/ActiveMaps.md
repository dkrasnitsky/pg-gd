# Актуальный список запущенных карт

**Статус:** готово, проверено.
**Расположение:** кнопка «Карты» в шапке Графика ивентов, рядом с «Синхронизировать с EventCenterConfig».

## Источник данных

**Таблица:** 1e_y2x7YRupUSDXxhpsiOLzKTcDE8yq4oahgRiNgNfHU (большая мульти-табовая таблица карт, много служебных листов — не всё относится к этой задаче).

**Пять листов режимов** (столбец A = список технических имён сцен, первая строка "Map" — заголовок, пропускается):
- Team Fight — gid 731056815
- Deathmatch — gid 1493905143
- Flag Capture — gid 1264631773
- Capture Points — gid 1704910560
- Duel — gid 1035921361

**Overview** (gid 1340983618) — общий справочник имён:
- Колонка **B (ENG)** — название карты в игре.
- Колонка **D (Prefab)** — техническое имя сцены (совпадает с тем, что лежит в листах режимов).
- Сопоставление: `readMapsOverviewNames()` строит `{Prefab → ENG}` один раз, дальше используется для всех 5 режимов.

## Что видит пользователь

По кнопке — модалка со списком по режимам, в формате:
```
TEAM FIGHT
pool  (Classic Pool)
dust_entering  (Sky Islands)
...
DEATHMATCH
...
```
Если для сцены нет соответствия в Overview — показывается только техническое имя без скобок.

## Примечания

- Никакой записи — только чтение, кнопка полностью безопасна.
- В самой таблице десятки других листов (справочники по уровням, бандлам, категориям и т.д.) — не задействованы, читаются только 6 нужных gid.
